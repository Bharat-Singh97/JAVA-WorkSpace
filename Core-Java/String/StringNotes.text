Q3. In JAVA String is special class?
Ans:- we can create String Object in 2 ways:-

1. using new keywords

String s1 = new String();

2. without using new keyword

String 2 = "Hare"

Note:-1.By using new keyword every time object gets created in heap area.
2. By using without new keywords String object gets memory in literal pool which part of heap area.

3. If in Literal pool if Object is already present no new Object created, same Object point by another reference.

4. And if Object not present in literal pool then new object created in literal pool.

Q4 String is Immutable?
Ans:- Whenever if we try to modify String Object new Object will be creating , existing Object won't change.

Example 1. 

String s1 = new String("Hare"); // immutable = unchanged

s1.concat("Krishna");
System.out.println(s1); // output = Hare

Example 2. How to create String immutable

String s1 = "Sita";
s1.concat("Ram");

System.out.println(s1);
